02 / Featured work

Medical text extraction with local LLMs.

Clear.bio · Production

Structured data from patient records, with zero data egress

Hospitals hold years of useful information in free-text notes, and they can't send it to a cloud API. I designed and deployed a pipeline that extracts it with open models running entirely on-premise.

  1. IngestPatient records enter through a Python backend service.
  2. ExtractLlama 3.1 and Meditron, served locally through Ollama.
  3. EvaluateModels compared on clinical accuracy and latency.
  4. DeployDocker, CI/CD and Ansible, to cloud and hospital servers.
  • The whole stack runs inside the hospital firewall, meeting data residency rules.
  • Model choice was made on measured results, not on reputation.
  • The same deployment works in cloud and on-premise environments.
  • Built with clinicians and data scientists, in a regulated setting.
